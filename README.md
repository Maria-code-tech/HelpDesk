HelpDesk — лабораторная работа по информационной безопасности

1. Описание проекта

HelpDesk — это веб-приложение для создания и управления заявками в службу технической поддержки.

Проект разработан на языке Python с использованием Flask и SQLite.

Цель лабораторной работы — продемонстрировать две уязвимости веб-приложения, показать способы их эксплуатации с помощью Python-скриптов и подготовить исправления.

2. Используемые технологии

- Python
- Flask
- SQLite
- HTML
- CSS
- Requests

3. Функциональность приложения

Приложение поддерживает следующие возможности:

- Регистрация пользователей.
- Авторизация пользователей.
- Создание заявок.
- Просмотр собственных заявок.
- Поиск заявок по названию.
- Выход из аккаунта.

4. Реализованные уязвимости

4.1. SQL Injection (OWASP A03:2021 — Injection)

Описание:

Уязвимость возникает из-за небезопасного формирования SQL-запроса с использованием пользовательского ввода.

Эксплуатация:

Для проверки используется Python-скрипт `exploit_sql.py`, который отправляет специальный поисковый запрос к приложению.

В результате эксплуатации удалось получить заявки других пользователей.

Исправление:

Использование параметризованных SQL-запросов вместо непосредственной подстановки пользовательского ввода.

4.2. Broken Access Control (OWASP A01:2021)

Описание:

В приложении реализован открытый маршрут `/users`, который позволяет получать информацию о зарегистрированных пользователях без авторизации.

В результате раскрываются логины и хеши паролей пользователей.

Эксплуатация:

Для проверки используется Python-скрипт `exploit_data.py`, который отправляет GET-запрос к маршруту `/users`.

Исправление:

Удаление открытого маршрута или добавление проверки авторизации и соответствующих прав доступа.

5. Скрипты эксплуатации

В папке `exploits` находятся:

- `exploit_sql.py` — демонстрация SQL Injection.
- `exploit_data.py` — демонстрация раскрытия информации о пользователях.

Для отправки HTTP-запросов используется библиотека Requests.

6. Исправление уязвимостей

- `fix_vulnerabilities.diff` — изменения для устранения двух реализованных уязвимостей.

7. Установка и запуск

Установка зависимостей

В терминале выполните:

```bash
pip install -r requirements.txt
```

апуск приложения

Перейдите в папку `Support system`:

```bash
cd "Support system"
```

Запустите приложение:

```bash
python app.py
```

Приложение будет доступно по адресу:

http://127.0.0.1:5000

### Запуск скриптов эксплуатации

При работающем приложении откройте отдельный терминал в корне проекта.

Запуск SQL Injection:

```bash
python exploits/exploit_sql.py
```

Запуск проверки раскрытия данных:

```bash
python exploits/exploit_data.py
```

Для SQL Injection необходимо использовать зарегистрированную тестовую учётную запись.
